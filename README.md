# Iron Fist Arena

Jogo de luta 2D desenvolvido com JavaScript, Phaser 4 e Vite. Os personagens são
desenhados em 2D no navegador e usam animações do Phaser para caminhar, atacar,
defender, pular e receber golpes.

## Executar

```bash
npm install
npm run dev
```

## Controles

- Movimento: `A` / `D`
- Agachar: `S`
- Pular: `W`
- Corrida: `Shift`
- Soco: `J`
- Chute: `K`
- Defesa: `L`
- Reiniciar: `R`

O adversário é controlado por uma IA básica. Abra em uma tela de 1280 x 720 para a experiência de referência.
